# Matemática Visual

Explicações de matemática animadas, passo a passo, pensadas para estudantes com TDAH.
Cada conceito aparece um passo de cada vez, com figuras e cores consistentes.

Conteúdo: circunferência (ângulos e cordas, ângulos excêntricos), triângulo retângulo
(inscrito, relações métricas, trigonometria), quadriláteros inscritos, probabilidade
e funções (relação binária, função, afim e quadrática).

Página única, sem dependências: abra o `index.html` no navegador
(ou publique com GitHub Pages).

Marca: Math Rz.
